# Slot-Machine (Python)
This is a terminal-based Slot Machine game I built, while continuing to practice Python fundamentals. It uses transposing to display the generated formations and takes the user’s input, deposits, to determine their winnings based on their bet amount.

-----
## What It Does ##
- Asks how much the user wants to deposit (and shares the balance)
- Instructs user to press enter to play (or 'q' to quit)
- Asks how many lines the user wants the bet on
- Asks how much the user wants to bet
- Shows the generated slot machine formations
- Determine the winnings/loses
- Handles valid inputs

-----
## Project Structure ##
```
SLOT_MACHINE/
│
└─ SLOT_MACHINE.py            # Main game logic
```

-----
## How It Runs ##
The script runs in the terminal: `SLOT_MACHINE.py`

You'll be asked to deposit an amout and it will be added to the balance, then you'll be asked how much you want to bet, on a the given amount of lines; and the games will display the slot machine and determine your winnings/loses.
